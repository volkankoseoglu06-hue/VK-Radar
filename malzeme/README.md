# VK Malzeme — Desktop

The interface is designed for desktop use (recommended 1366px+ screen). It is a browser-based desktop app, not a mobile-first app.

## Open locally
1. Download `index.html` from this folder.
2. Open it in Microsoft Edge or Google Chrome.
3. Internet access is needed for the XLSX library; the search opens source pages in your browser.

## Current capabilities
- Import an Excel / CSV material list, run line-by-line theoretical weight calculations where enough dimensions and a recognizable material are present.
- Export analysis to XLSX.
- Search helper opens Türkiye-focused queries for materials and standard parts.
- Single-part calculator for plate, round bar, rectangular bar, angle and hollow section.

## Important limitations
- Search helper opens supplier/search result pages; it does not scrape all live prices automatically.
- Do not treat inferred standard family, material grade or approximate profile geometry as approved design data. Verify against the controlled CATIA library, drawing and material certificate.
- No TUSAŞ internal or confidential standards are included by default.
